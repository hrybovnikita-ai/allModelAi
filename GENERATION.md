# Генерация приложений и изображений

## Приложения

Войди в аккаунт, открой **App Builder** в боковом меню чата (адрес `/app-builder`), опиши приложение и нажми **Create app**.

Например: «Список задач: добавление, отметка выполнения, удаление и фильтр выполненных задач».

Backend `/api/apps/generate` использует существующие подключения моделей и Smart Router, проверяет сессию и ограничения аккаунта. Результат — интерактивное браузерное приложение из HTML, CSS и JavaScript. Его можно редактировать, просматривать в размерах телефона/планшета/компьютера и скачать одним HTML-файлом. Файлы сохраняются локально в браузере; при ошибке сохранения появляется уведомление. Неполный ответ ИИ не заменяет предыдущие файлы.

Предпросмотр изолирован от AllModelAi, сетевые запросы отключены. Генератор не разворачивает сервер, базу данных, платежи или авторизацию для созданного приложения. Существующий адрес `/website-builder` также работает.

## Изображения

Кнопка **Create image** в чате и App Builder открывает форму. Введи описание и нажми **Сгенерировать изображение**. Результат показывается непосредственно в окне; ссылка под картинкой позволяет открыть или сохранить её. Закрытие окна прерывает ожидание ответа в браузере, но провайдер мог уже начать выполнение запроса.

Ключи остаются в `backend/.env`. Существующий backend поддерживает OpenAI-совместимый сервис (`IMAGE_API_KEY`, при необходимости `IMAGE_API_URL`, `IMAGE_MODEL`) или Cloudflare (`IMAGE_PROVIDER=cloudflare`, `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_KEY`). Не добавляй реальные ключи в frontend или репозиторий.

При проверке 18 сентября 2026 года реальная генерация приложения вернула полный набор файлов. Сервис изображений ответил HTTP 429: исчерпан лимит. Для получения картинки нужно восстановить квоту/баланс у провайдера либо настроить другой доступный сервис. Интерфейс показывает эту ошибку и позволяет повторить запрос.

## Модель и проверки

Используются уже подключённые модели с инструкциями для генерации приложений. Обучение или дообучение весов не проводилось: для него отдельно нужны выбранная базовая модель, датасет, вычислительные ресурсы и критерии качества.

Проверки:

```sh
cd backend
node --test tests/app-generation.test.js tests/images.test.js
cd ../frontend
node --test tests/app-generation.test.mjs
npm run build
```

API-тесты используют подменённый ответ провайдера и не расходуют средства. Реальная проверка сервисов выполнялась отдельно.
